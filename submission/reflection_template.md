# Assignment Reflection

Write 300–500 words in your own language. Use this structure rather than copying a ready-made reflection.

## Project summary

Briefly explain the pipeline you created, from PyTorch training to Docker and Kubernetes serving.

## Most challenging part

Describe one genuine difficulty. Examples include volume mounting, Docker image size, Kubernetes image access, PersistentVolumeClaims, or readiness probes. State the exact error or symptom.

## How the problem was solved

Explain the troubleshooting steps you performed, the commands you ran, and why the final correction worked.

## What you learned

Discuss what became clearer about the difference between a container, a Kubernetes Job, a Deployment, a Service, and persistent storage.

## Possible improvements

Mention realistic future improvements such as model monitoring, authentication, experiment tracking, GPU scheduling, or a cloud storage class.
